01

전체 사용 흐름

별도의 로그인 절차 없이 접속 즉시 데이터 입력을 시작합니다. 아래 순서는 실제 화면에서 진행되는 흐름 그대로입니다.

접속

브라우저로 접속하면 로그인 화면 없이 Dashboard로 바로 이동합니다.

Subject 등록

Subjects 화면에서 Subject ID를 직접 입력합니다. 이미 등록된 ID는 자동으로 거절되며, 등록에 성공하면 T1·T2·T3 방문이 자동으로 생성됩니다.

방문일 입력

Subject 상세 화면에서 T1·T2·T3 방문일을 입력합니다. 방문일이 없으면 “방문일을 입력해 주세요” Query가 자동으로 발생합니다.

eCRF 입력

방문별로 변수를 입력합니다. 범주형 항목은 select에서 선택하며, 비활성화(회색)된 칸은 조건상 입력 대상이 아닙니다.

자동 저장 저장 버튼 없음

입력을 마치고 약 400ms가 지나면 자동으로 저장됩니다. 화면 상단의 저장 상태 표시를 반드시 확인합니다.

Query 확인 · 해결

저장 시 값 검증이 자동 실행되어 오류가 있으면 Query가 생성됩니다. 값을 올바르게 수정하면 해당 Query는 자동으로 Resolved 처리됩니다.

Export

Export 화면에서 대상자·방문 범위를 선택하고 필요 시 Query 시트를 포함해 XLSX 파일로 내려받습니다.

02

화면 구성

사이드바에 표시되는 화면입니다. 음영으로 표시된 두 화면은 관리자 비밀번호 확인 후에만 접근할 수 있습니다.

Dashboard
등록 인원, Open Query 수, 방문별 입력 진행률을 한눈에 확인합니다.
Subjects
대상자 등록·검색·삭제. 삭제 시 연결된 모든 데이터가 함께 삭제됩니다.
Subject 상세
방문일·eCRF 입력, EMR Reference 확인, Query 필터가 이루어지는 실제 작업 화면입니다.
Queries
대상자별 현재·과거 Query 목록. 행을 선택하면 해당 입력 항목으로 이동합니다.
Export
범위를 선택해 XLSX로 내려받습니다. 별도 비밀번호 제한은 없습니다.
Rule Master
변수 정의(범위·범주·조건)를 수정하는 화면입니다.
관리자 비밀번호 필요
03

저장 상태 확인하는 법

별도 저장 버튼이 없기 때문에, 값을 입력한 뒤에는 반드시 화면의 저장 상태 표시를 확인해야 합니다.

Saved

정상적으로 저장이 완료된 상태입니다. 다음 항목으로 이동해도 됩니다.

Saving…

저장이 진행 중입니다. 이 표시가 사라지기 전에 창을 닫지 않습니다.

Save failed

저장에 실패한 상태입니다. 네트워크 연결을 확인한 뒤 값을 다시 입력합니다.

04

05

변수의 자료형에 따라 화면에 표시되는 입력 방식이 다릅니다. 체크박스·라디오 버튼은 없습니다.

06

꼭 알아야 할 주의사항

Subject 삭제는 되돌릴 수 없습니다

삭제를 확정하면 해당 대상자의 입력값·방문·Query·Export 기록이 모두 함께 영구 삭제됩니다.

EMR Reference는 입력값이 아닙니다

변수 옆에 표시되는 EMR 위치 정보는 참고용 안내이며, 값을 그대로 옮겨 적는 항목이 아닙니다.

관리자 비밀번호는 개인 계정이 아닙니다

Rule Master·Audit Trail 화면 접근용 공용 비밀번호이며, 확인 후 30분 동안만 해당 브라우저 탭에서 유효합니다.

XLSX Export는 전체 백업이 아닙니다

Export 파일은 열람·제출용 다운로드이며, 데이터베이스 전체를 복구하기 위한 백업 파일을 대체하지 않습니다.

개인 계정·로그아웃 기능은 아직 없습니다

현재는 사용자별 로그인·역할 구분 없이 하나의 화면을 함께 사용하는 구조이므로, 입력 시 담당자 간 소통이 필요합니다.
